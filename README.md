# 🌿 My Planner

A clean, minimal, and responsive task management web application built with **HTML**, **CSS**, and **JavaScript**.

Designed to help users stay organized, track progress, and manage daily tasks with a calming nature-inspired interface.

---

## ✨ Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 📊 Dynamic progress bar with completion percentage
- 💾 Local Storage support (tasks persist after refresh)
- 📅 Displays the current date dynamically
- 🌙 Greeting based on time of day
- 🌿 Beautiful empty state when no tasks exist
- 🎨 Custom-styled checkboxes
- 📱 Responsive and clean UI

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/smritiy06/Planner.git
```

Navigate to the project folder:

```bash
cd Planner
```

Open `index.html` in your browser.

Or use the **Live Server** extension in VS Code.
